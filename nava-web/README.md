# 🕉️ Nava Web Playground (नव्या-क्रीडाङ्गणम्)

यह फोल्डर (`nava-web`) Nava Sanskritam का **Web Playground** है। यह एक पूर्णतः ब्राउज़र-आधारित ऑनलाइन सङ्कलक (compiler) और UI रेंडरिंग इंजन है, जो डेवलपर को ब्राउज़र में ही सीधे `.ns` (Nava Sanskritam) कोड लिखने, सङ्कलन (compile) करने और लाइव आउटपुट देखने की सुविधा देता है।

## 🚀 मुख्य घटक (Core Components)

इस परियोजना में मुख्य रूप से तीन घटक शामिल हैं:

1. **`index.html`**:
   - यह मुख्य वेब पेज है जिसमें यूजर इंटरफ़ेस (UI) परिभाषित है।
   - यह Tailwind CSS का उपयोग करके डिज़ाइन किया गया है और दो मुख्य भागों में विभाजित है:
     - बायां भाग: कोड एडिटर (Monaco Editor)।
     - दायां भाग: कंसोल आउटपुट और लाइव UI (दर्शनम्)।

2. **`playground.js`**:
   - यह मुख्य जावास्क्रिप्ट फाइल है जो पूरे वेब प्लेग्राउंड के तर्क (logic) को संभालती है।
   - इसमें **Monaco Editor** का सेटअप है, जो सिंटैक्स हाइलाइटिंग (Syntax Highlighting) प्रदान करता है, विशेष रूप से Nava Sanskritam के कीवर्ड (जैसे `दर्शनम्`, `अस्ति`, `वद`) के लिए।
   - यह **WebAssembly (`nvc.wasm`)** मॉड्यूल को लोड और प्रारंभ करता है।
   - **`createDrishyam` फ़ंक्शन**: यह फ़ंक्शन JSON आउटपुट को लेता है (जो WASM कंपाइलर द्वारा उत्पन्न होता है) और उसे वास्तविक HTML DOM एलिमेंट्स में बदलता है। यही वह जगह है जहाँ `मंजूषा` (Box), `बटनम्` (Button), `चित्त्रम्` (Image), आदि वेब घटकों में परिवर्तित होते हैं।

3. **`nvc.wasm` & `nvc.js`**:
   - यह C++ में लिखे गए मुख्य Nava Compiler (`nvc`) का WebAssembly (WASM) संकलित रूप है।
   - ब्राउज़र में कोड निष्पादन (execution) सीधे क्लाइंट-साइड पर होता है। जब आप "चलाओ" बटन दबाते हैं, तो `playground.js` एडिटर के कोड को `nvc.wasm` को भेजता है। कंपाइलर इसे प्रोसेस करता है और JSON प्रारूप में UI संरचना (AST/Darshanam) वापस करता है।

## ⚙️ यह कैसे काम करता है? (How it works?)

1. **कोड इनपुट**: उपयोगकर्ता Monaco Editor में Nava Sanskritam कोड लिखता है।
2. **सङ्कलन (Compilation)**: "चलाओ" पर क्लिक करने पर, जावास्क्रिप्ट कोड को `compileSanskrit` (WASM बाइंडिंग) के माध्यम से `nvc.wasm` में भेजता है।
3. **JSON निष्कर्षण**: C++ कंपाइलर कोड को प्रोसेस करता है और अगर कोड में UI (दर्शनम्) घटक हैं, तो यह एक JSON स्ट्रिंग लौटाता है जो UI की संरचना का वर्णन करता है। `extractJson` फ़ंक्शन इस JSON को कंसोल आउटपुट से अलग करता है।
4. **रेंडरिंग (Rendering)**: `createDrishyam` फ़ंक्शन इस JSON डेटा को पढ़ता है और तदनुसार HTML घटक (div, button, img, input आदि) बनाता है और उन्हें `#sul-root` कंटेनर में जोड़ता है।

## 🎨 दर्शनम् (Live UI Rendering)

`createDrishyam` फ़ंक्शन Nava के UI घटकों को निम्नलिखित HTML घटकों में मैप करता है:
- **`मंजूषा` (Box)**: `<div>`
- **`बटनम्` (Button)**: `<button>`
- **`पाठः` / `सूची` (Text/List)**: `<p>` या `<ul>`/`<li>` (अद्यतन के बाद)
- **`चित्त्रम्` (Image)**: `<img>`
- **`प्रविष्टिः` (Input)**: `<input>`

## 🛠️ विस्तार (Extensibility)

इस प्लेग्राउंड को और भी शक्तिशाली बनाने के लिए, `playground.js` में `createDrishyam` फ़ंक्शन को अनुकूलित किया जा सकता है, जैसे कि:
- बटन के क्लिक पर अलर्ट या कस्टम इवेंट्स जोड़ना।
- इनपुट फ़ील्ड्स के लिए `onChange` इवेंट्स को संभालना।
- और अधिक जटिल लेआउट संरचनाओं (जैसे ग्रिड, पंक्तियां) को समर्थन देना।
